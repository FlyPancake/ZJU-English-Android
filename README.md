# 大英默写器 · KRY 安卓移植版

这是依据所提供仓库的词书和学习规则制作的非官方 Android 移植版，不是把 Windows EXE 改名成 APK。界面使用应用内置 WebView，朗读、保存和文件选择由原生 Android 接口实现；无需网页服务器。

## 安装

1. 把 `ZJU-English-KRY-Android-v1.1.2.apk` 发送到手机。已安装先前版本时可直接覆盖更新，建议先导出学习备份，不要先卸载。
2. 从文件管理器打开安装包，按系统提示允许该文件管理器安装未知来源应用。
3. 安装后打开「大英默写器 · KRY」。要求 Android 8.0 及以上，以及支持现代 JavaScript 的 Android System WebView；旧手机请先更新 WebView 或 Chrome。
4. 听写前在设置中打开「系统英语语音设置」，安装英语语音包。朗读音色和离线能力取决于手机的语音引擎。

应用本身没有联网权限，也不申请整个存储空间权限。词书和练习可离线使用；文件通过系统文件选择器导入或导出。手机语音引擎是独立服务，是否联网由其自身设置决定。

## 功能

- 内置 book2、book3，共 32 个单元；合并同名词后有 1,544 个逻辑单词，保留释义、词性和去重例句。
- 自由练习：词书、多个单元、词数、错题 / 易错词 / 尚未学习筛选。
- 每日新学：按每日数量抽取，优先词优先，先预览再答题；未完成词在结束后可重新抽取。
- 新词预览按三层累计展示：单词和音标 → 例句 → 完整中英释义。每次点按钮只增加一层；第三层后才能切换下一词或开始答题。切换词条重置到第一层，暂停、重启和备份恢复保留当前层。
- 音标离线保存，来自 ECDICT；1,238 个词直接采用词典音标，196 个词组按组成词标注，110 个缺失条目明确显示「暂无音标」，不生成未经查证的读音。自定义 CSV 可添加 phonetic 或 ipa 列。
- 1.1.0 图标使用用户提供的插画透明背景版；仅移除外部白背景，保留人物、白色头发、衣物及装饰。部分手机桌面可能为图标自动添加底板。
- 到期复习、历史列表复习、错题和易错词集中复习。
- 例句填空、英语听写、中文拼写；四模块独立设置题型、题型先后及顺序 / 单元内随机 / 词书内随机。
- 例句按句中实际词形作答，如 sprawling；同词多条例句分别出题。
- 空输入提交按阶段显示首字母和释义；输入非空时直接判定。
- 错题队列末尾复现；复现答对才增加完成数。自由练习可以关闭复现。
- 错题本、易错本、已掌握、优先学习、最近作答；搜索、移动、手动「斩」和自定义可接受答案。
- 三项首次答对门槛同时满足才从错题转入易错本，每词每列表每题型计一次；不自动标记已掌握。
- 1.1.1 修复「斩 · 已掌握」：使用应用内确认框，确认后立即切换到下一个未掌握词或进入剩余答题，跳过该词全部题型和复现，不计答错；所有题目已掌握时结束本轮。旧版已标记却仍停留的预览在恢复时自动跳过。未结束的学习列表可以撤销最近一次标记。
- 字符位置拼写差异、撤销最近 5 次答题操作、只读回看。
- 暂停和跨重启恢复，包括队列、输入、提示、答题反馈；有效学习计时、统计和当月学习日历。
- 自动保存；学习中每 10 分钟 / 提前结束时保留本地快照，最多 5 份。
- 完整安卓 JSON 备份导入 / 导出、自定义 UTF-8 CSV 词书导入、旧版 `wrong_words.json` 数组导入。
- 美式 / 英式朗读、语速、音量、自动朗读；深浅主题、图片壁纸、循环视频、面板透明度。
- 1.1.2 朗读规则：开启「新学首次自动朗读」时，同一学习列表中每个新词首次预览自动朗读一次；成功开始播放后记录已朗读，切换提示层、回看和恢复不重复。例句填空、中译英及其复现不自动读答案，只有点击朗读按钮才播放。听写仍自动朗读，不受该开关影响。
- 手动朗读不受自动朗读开关或已朗读记录限制。初始化未完成时保留最新请求；失败或引擎没有响应时自动重连重试一次，并提示原因。检查应用音量、系统媒体音量、英语语音包；从系统语音设置返回时重新初始化引擎。默认优先使用已安装的离线英语声音，口音不可用时回退其他英语声音。

## 与 Windows 原版的差异

这是核心学习功能的安卓实现，并非原版全部细节的逐项复制：

- 不包含 Windows 多窗口、键盘快捷键体系、窗口独立外观批量应用、原版动态皮肤文件库和 GitHub 自动更新 / 回滚。
- 每次只能有一个活动学习列表，学习计划针对当前词书；没有移植原版多词书同时配额抽取和所有跨日结算选项。
- Windows `study_state.json` / `notebooks.json` / ZIP 备份不能直接恢复；安卓备份使用独立格式。旧版错题 JSON 数组可合并导入。
- 朗读使用 Android 文字转语音，不使用 Windows System.Speech。没有英语语音包时需要先安装，不能保证所有品牌手机自带英语声音。
- 自定义可接受答案需开启设置中的相应开关；不自动把答错拼写视为正确。
- 当前日历显示当月；统计正确率按实际作答次数计算，包含复现，零作答显示未作答。
- 壁纸、视频文件不包含在 JSON 备份中；恢复后如需壁纸应重新导入。
- 输入和操作后立即保存，学习时钟约每 10 秒落盘；系统强制终止时可能损失最后数秒计时。正常切后台会暂停并保存。
- 撤销记录只保留在本次进程中；学习队列和反馈可跨重启恢复。
- 没有自动云同步和账号。

卸载或清除应用数据会删除本地学习记录，请先导出备份。安装后首次使用建议只抽取 1–2 个词，确认手机的朗读和文件选择器可用。

## 本地构建

需要 Windows PowerShell、JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。不需要 Gradle、Android Studio 或任何在线运行服务。

```powershell
$env:KRY_STORE_PASSWORD = '你的签名库密码'
.\build.ps1 -JavaHome 'C:\tools\jdk-17' `
  -BuildTools 'C:\Android\Sdk\build-tools\35.0.0' `
  -AndroidJar 'C:\Android\Sdk\platforms\android-35\android.jar' `
  -KeyStore 'C:\private\kry-android.p12'
```

默认签名别名 `kry-android`，编译中间文件写入工作目录，APK 输出到源码目录的上一级。可通过参数覆盖这些路径。`assets/data.json` 已包含完整内置词书，不需要重新拉取原仓库。

如需重新生成词书：

```powershell
node .\tools\prepare-data.js 'C:\path\to\upstream'
node --test .\tests\engine.test.js
```

`assets/phonetics.json` 已包含离线音标子集，重新生成词书会保留音标。需要重新提取时，下载上述来源的 `ecdict.csv` 后运行 `node tools/prepare-phonetics.js C:\path\to\ecdict.csv`。图标处理工具为 `tools/prepare-icon.ps1`，只对与图片边缘连通的白色背景做透明化，避免删除人物的白色区域。

手机界面集成测试需要另行安装 Playwright，并设置 `KRY_CHROME` 为 Chrome 的完整路径，再执行 `node tests/ui.integration.js`。如 Playwright 不在默认依赖路径，可设置 `KRY_PLAYWRIGHT_MODULE`。

朗读界面回归测试运行 `node tests/speech.integration.js`，使用相同 Playwright 环境。原生协调器可用 JDK 运行：

```powershell
javac -encoding UTF-8 -d build-speech-tests src/com/kry/zjuenglish/SpeechController.java tests/SpeechControllerTest.java
java -cp build-speech-tests SpeechControllerTest
```

本次 APK 使用个人构建签名。配套「签名密钥-请勿分享.zip」仅供你保留以便将来用同一签名覆盖更新，不要公开发布或将它与安装包一起分享；公开源码压缩包不包含密钥。不使用同一签名构建的 APK 不能直接覆盖安装本次版本。
